# 拾忆 · SHIYI

桌面优先、手机自适应的面试学习 Web 应用。整理题目，用间隔复习建立记忆，划选不懂的句子向 AI 追问。

## 本地运行

需要 Node.js **24 或更新版本**。

```powershell
cd F:\Project\interview-memory
npm ci
npm run dev
```

打开 <http://localhost:3000>，创建自己的账号。首次启动会生成独立随机密钥，保存于忽略提交的 `.env.local`，并自动应用数据库迁移。数据库落盘到 `.data/postgres`，重启不会丢失。不要同时启动多个进程访问同一份嵌入式数据库。

局域网访问：开发服务已监听 `0.0.0.0:3000`。在 `.env.local` 中设置 `BETTER_AUTH_TRUSTED_ORIGINS=http://你的局域网IP:3000`（多个地址用逗号分隔，不加空格），重启 `npm run dev`，并在系统防火墙允许局域网设备访问 TCP 3000 端口。其他设备打开该地址即可；`localhost` 仍可使用。此配置同时允许登录、接口写入及 Next.js 开发资源访问。

没有安装 PostgreSQL 或 Docker 也能体验：开发环境使用 PGlite（嵌入式 PostgreSQL）。填写 `DATABASE_URL` 后会使用标准 PostgreSQL，表结构、Drizzle 查询与迁移一致。生产环境默认要求标准 PostgreSQL。

账号不预置默认密码。首页可载入明确标注的示例面试题，也可直接导入自己的资料。

## 已实现的功能

- 邮箱密码注册、登录、退出和账号数据隔离。
- 题库作为分类，删除题库后题目保留在“未分类”；支持在题库间移动题目、搜索、标签、收藏、待整理及归档。题目可单独删除，回收站保留 30 天，期间恢复会保留答案、笔记和复习进度。
- 粘贴文本或读取 UTF-8 的 `.md` / `.txt` 文件，自选自动切分、AI 解析或整篇保留；预览中编辑、勾选、合并后确认入库，重复内容跳过。完整原文单独保存，所有者可查看和下载。
- 导入区分“题目与答案”和“只有题目”。自动切分时按每行一题识别，支持编号、列表及 Markdown 标题，也可选择 AI 解析；进入待整理，同题库已有的同名题目跳过。
- 待整理列表和无答案学习卡提供“AI 写答案”：使用当前账号的模型生成草稿，可补充要求、重新生成、编辑和恢复草稿；点击保存后才成为参考答案并进入可复习的新题。
- 整页编辑题目，正文和追问共用一份内容；支持富文本、Markdown 原文、自动识别及选中问答手动指定追问。整篇粘贴多道主问题时先预览切分，再确认更新当前题或全部新增。编辑、导入及笔记草稿按账号保存在当前浏览器。
- 整题默写和口述答题；对照参考答案后自评，作答随复习记录按账号保存，可在回顾记录中展开。
- 段落原地默写，支持单段、嵌套列表中的单个要点或整篇遮挡，对照后可重写。草稿按账号、题目版本和段落保存在当前浏览器；不会覆盖参考答案。
- 正文、追问、笔记、记忆分栏；面试追问用独立卡片切换并按需翻答案。AI 侧栏默认收起，划选仍可随时提问。
- FSRS-7 调度，先回忆再展开答案、四档评分、下次复习时间、单题预测遗忘曲线、学习热力图与历史记录。默认每日目标 5 道、最多新学 3 道；同题当天重复评分计一道，可在设置中调整，题库仍可自由练习。
- 复习事件幂等、复习状态和笔记的版本检查；重复提交不会重复推进记忆状态。
- 每人填写 OpenAI 兼容接口的 Base URL、API Key 与模型名；提供 OpenAI、DeepSeek、自定义预设。密钥按用户加密保存，支持替换、删除和测试连接。
- 答案中划选文字后解释、举例、追问；右侧 AI 对话栏，手机底部面板；流式回答、多轮对话、引用快照和内容版本保留；解释可以保存为私人笔记或独立卡片。
- 题库草稿与发布版本分开。公开发布或通过链接分享，其他用户可持续订阅；作者发布新版本才会传播修改；更新不覆盖订阅者的笔记和复习状态。
- 重要知识修正提醒重新复习；归档题目仍保留历史；取消订阅停止接收更新，重新订阅后原有学习状态仍可恢复。
- 个人数据 JSON 导出，包含原文、笔记、完整复习历史和对话，不包含 API Key。
- 明暗主题、每日目标、中文排版和响应式界面。

第一版以联网使用为主；页面打开、重新获得焦点和每分钟会读取云端最新状态。没有离线同步或 PWA 安装能力。

## 题库、题目与回收站

题目独立归属于用户，题库用于分类。删除题库只移除分类，内含题目进入“未分类”，题库不进回收站。题目卡片及阅读页的三点菜单可移动或删除题目；没有题库时也能直接导入到“未分类”。

删除题目后从学习列表中移除，在回收站保留 30 天，显示剩余天数；到期前恢复，答案、私人笔记和复习进度保留。原题库已删除时恢复到“未分类”，可再移动到新题库。归档仅暂停日常学习，不属于删除，也没有 30 天期限。

已发布内容与作者草稿独立：删除题库后，原订阅者保留最后发布版；删除题目需发布更新才从订阅版移除。题目跨题库再次发布时使用各自稳定的发布标识，订阅者的笔记和复习进度互不混淆。

Node 服务启动及每小时清理过期题目；读取回收站和导出也会触发清理。超过 30 天即不能恢复，清理本人题目内容和对应私人笔记、作答、聊天，不删除其他订阅者的数据。仍被其他题目引用的完整导入原文及已发布快照按独立来源保留。

## 编辑题目

题目菜单 → 编辑题目，进入整页编辑。正文和追问写在一起，文档 / 原文可切换；预览展示学习时的正文与追问，不提供第二套追问编辑区。已有 Obsidian 标记、公式等复杂原文默认用原文模式打开。

系统识别 `> [!question]`、`## 追问` / `## 面试追问` 下的 Q/A、问/答、编号问题和问句小标题。无法完整识别的内容仍留在正文；也可选中一段问答，点“指定追问”，或用“插入追问”在同一篇内容里补充。

粘贴多道主问题后，可选择“保留为当前一题”，或“预览切分”。切分预览允许选择自动 / AI / 整篇解析，检查、合并和勾选后再保存。只有唯一同名项时才默认选为更新当前题，其余情况默认全部新增；“当前题的处理”可手动调整。更新当前题会保留题目 ID、标签、私人笔记和复习记录，其余题目新增。版本冲突时整批停止，草稿保留。

未保存的编辑草稿按账号、题目和起始版本保存在本机；重新进入会恢复。其他页面已保存新版本时，需要先查看并合并，再明确保存。只修改标题或标签不会重写原答案的 BOM、换行和空格。

## 导入方式

打开“导入面试题”，选择资料类型、目标题库和解析方式，再粘贴或读取文件：

````markdown
## 什么是闭包？

闭包是函数与其词法环境的组合。

```javascript
function counter() {
  let n = 0;
  return () => ++n;
}
```

## 什么是事件循环？

先说明调用栈，再解释任务与微任务的执行时机。
````

点击“解析并预览”，检查题目与答案，可修改标题或答案、取消选择、合并相邻题目、删除误切项或手动补题；最后点“确认入库”。原文或解析方式改变后必须重新解析。关闭窗口会保留当前账号的本地草稿和预览，粘贴本身不会入库或调用模型。

自动切分识别 Markdown 标题、Q/A 和编号，不调用模型；AI 解析使用本人的连接，每批最多 25000 字符，只标记原文行号，答案按位置从原文提取；整篇保留不拆分正文。自动切分同样按原文位置提取答案，保留换行和空格；超长标题先在预览中修改，不静默截断。AI 结果异常或截断时不产生题目，可重试或换解析方式。原文独立保存，所有者在题目菜单中可查看或下载，订阅者不能访问整批私有原文。

文本最多 10 万字符，UTF-8 `.md` / `.txt` 文件不超过 400 KB；暂不支持直接读取 PDF、Word、图片或网页。其他格式可先转成文本再导入。

只有题目时，选择“只有题目”，每行放一道题：

```text
什么是闭包？
1. 为什么需要数据库索引？
- CAS 是什么？
```

点击“解析并预览”，确认每道题后点“确认入库”，再点“去补答案”。没有答案时不会计入可复习的新题，首页会提示先补答案。每批最多 200 道题，单个题目最多 200 字；编号不影响拆分。

“AI 写答案”只针对自己题库中尚无答案的题目，不在导入时自动调用模型。生成后可以编辑，或填写补充要求再重新生成；点击“保存为参考答案”才写入题库。关闭窗口后，草稿按账号、题目及版本留在当前浏览器；保存后的答案随账号同步。已有参考答案不自动覆盖，其他页面的修改会触发版本冲突并保留草稿。订阅内容需先另存个人副本再补充答案。

导入脚本会核对快照哈希，重复执行不重建卡片或清空学习状态；同一路径的原文有变化时会停止，需重新核验后处理。源目录在导入期间发生过外部编辑，本次以清单记录的快照为准。

```powershell
# 仅校验快照并生成报告
npm run library:import -- --source content/interview-original --dry-run
```

## AI 与密钥

设置 → AI 连接 → 选择预设，填写 Base URL、API Key 与模型名 → 保存连接。测试连接使用当前表单，测试本身不保存或替换配置；短请求产生的费用计入用户自己的模型服务账号。普通导入和复习不需要 Key。

统一使用 OpenAI Chat Completions 协议。预设只填入地址和模型建议，模型名仍可手动修改；聊天、AI 导入和连接测试共用同一份连接配置。Base URL 填接口根路径（例如 `https://api.example.com/v1`），也兼容粘贴完整的 `/chat/completions` 地址。DeepSeek 预设参考[官方兼容说明](https://api-docs.deepseek.com/)，OpenAI 请求参数参考[Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

省略 Key 时仅保留相同 Base URL 下已保存的 Key；换到其他接口后需要重新填写。原有 DeepSeek 配置会保留原模型和加密密钥，迁移后仍走原地址。

自定义地址使用公网 HTTPS，拒绝 URL 中的账号密码及查询参数，不跟随重定向；DNS 检查后的地址直接用于连接。若本机代理使用 `198.18.0.0/15` 虚拟地址，OpenAI 和 DeepSeek 官方来源可直接使用；其他网关由服务器管理员在 `.env.local` 中配置准确的 `AI_PROXY_TRUSTED_ORIGINS=https://your-gateway.example.com`，多个来源用逗号分隔。此配置只允许代理虚拟网段，仍不开放回环、私网和云元数据地址。

随文对话只发送当前题目、选文及有限的当前对话上下文；AI 解析发送本批原文及行号；AI 写答案只发送所选题目、标签及补充要求。输出不会自动替换原答案。

密钥是**服务端托管加密**：应用服务器在请求模型时会解密使用，不能把这称为端到端加密。`KEY_ENCRYPTION_SECRET` 应与数据库分开保存并备份；直接更换该主密钥会让已有用户 Key 无法解密，需迁移或让用户重新配置。密钥不会返回页面，也不应进入日志或数据导出。

## 订阅规则

1. 作者编辑的是草稿，点击“发布题库 / 发布更新”生成不可变的内容快照。
2. 公开题库显示在“发现题库”；仅链接题库通过订阅链接访问。
3. 订阅者自动读取最新发布版本，看到更新提示；题目使用稳定 ID，与个人学习数据关联。
4. 文字修改保留原调度；标记为重要知识修正时提示重新复习，不删除历史。
5. 订阅者不能修改作者原题，可写个人笔记、保存 AI 补充或另存独立副本。
6. 作者归档题目后重新发布，该题退出常规复习，但原笔记与记录保留。AI 对话保留当时的选文、答案快照和版本。

这里的“订阅”表示持续接收内容更新，当前不涉及付费订阅。

## 云端部署

同一应用部署到服务器后，电脑和手机访问同一个 HTTPS 地址，使用相同账号即可同步。

使用 `Dockerfile`、`compose.yaml` 和 [部署说明](deploy/README.md)。镜像使用 standalone 产物，容器启动前执行数据库迁移，并通过 `/api/health` 检查数据库状态。项目根目录创建忽略提交的 `.env`，填写：

```dotenv
BETTER_AUTH_URL=https://your-domain.example
BETTER_AUTH_SECRET=GENERATE_A_RANDOM_SECRET
KEY_ENCRYPTION_SECRET=GENERATE_A_DIFFERENT_RANDOM_SECRET
POSTGRES_PASSWORD=GENERATE_A_DATABASE_PASSWORD
```

每次运行下面的命令生成一个独立随机值。不要将真实值提交到 Git：

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
docker compose up -d --build --wait
```

提供 [Nginx 配置](deploy/nginx.conf)，反向代理连接 `127.0.0.1:3000`，关闭 API 缓存和流式缓冲。密钥校验失败或数据库迁移失败时容器不会启动。请备份 PostgreSQL 数据与加密主密钥；当前按单应用实例部署，Docker / 标准 PostgreSQL 需在目标服务器实测。

本地生产构建体验先停止开发服务器，设置 `ALLOW_LOCAL_DATABASE=true`，依次执行 `npm run db:migrate`、`npm run build`、`npm run start`。标准 PostgreSQL 的非 Docker 部署也要在启动前执行 `npm run db:migrate`；生产请求不自动修改表结构。

## 清理生成文件

停止开发、预览和测试服务后执行：

```powershell
npm run clean -- --dry-run
npm run clean -- --cache
```

清理仅覆盖 Next.js 构建、测试结果、测试数据库、TypeScript 缓存及可选的项目 npm 缓存。日常数据库 `.data/postgres`、备份、导入记录、原文、账号和 `.env.local` 均保留。日常开发直接运行 `npm run dev`；清理后需要重新构建才能启动生产服务。

## 项目结构

```text

src/components/       题库、阅读、复习、AI 与设置界面
src/server/           权限、内容版本、AI 调用、加密与调度
src/db/               Drizzle PostgreSQL 表结构与连接
src/lib/              导入解析、客户端类型与工具
drizzle/              已生成的 SQL 迁移
deploy/               容器迁移入口、HTTPS 代理及部署说明
tests/                核心、后端集成与浏览器流程测试
```

后续功能：个人 JSON 备份恢复、邮件验证与密码重置、批量管理、离线复习。当前未接入邮件服务，忘记密码后不能通过页面自助重置；公开运营前应补齐邮件验证/找回和目标环境的运维验证。
